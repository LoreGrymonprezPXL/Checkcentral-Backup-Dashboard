# ADR-0003: Geen maatwerkscripts, enkel ingebouwde parsing

- **Datum:** [YYYY-MM-DD]
- **Status:** Aanvaard

## Context
Collega's hebben geen programmeerkennis; oplossing moet onderhoudbaar blijven.

## Beslissing
Uitsluitend ingebouwde CheckCentral-parsing; geen Python/Office-scripts.

## Gevolgen
Moeilijke mailformaten oplossen via rule-aanpassing of aangepaste mailinstellingen bij de bron.
